## energy_demand_daily.csv

A daily electricity demand series for an imaginary region, from 2015-01-01 to 2024-12-31 (3653 rows). The series is synthetic on purpose. It carries no license or privacy risk, and the true data-generating process is known, so you can check what a model recovers.

The generator builds the series from these parts:

- A linear trend of 0.12 GWh per day on a base of 1200 GWh.
- A weekly pattern: weekends about 110 GWh lower, Mondays about 15 GWh lower.
- A temperature effect: demand rises by 6.5 GWh per degree away from 18 degrees C, for heating and cooling.
- A holiday effect: 140 GWh lower on fixed-date holidays (Jan 1, May 1, Dec 24, 25, 26, 31).
- Autocorrelated noise: an AR(1) process with coefficient 0.6.
- A structural break: a demand shock that starts on 2020-03-15 and decays over about four months.
- Six outliers of 250 to 400 GWh, added at random dates.

Run `python scripts/make_data.py` to regenerate the file. The output is identical for the same Python, NumPy, and pandas versions.

## Optional real data (not bundled)

Notebook 03 can download the public Open Power System Data daily series for Germany and use it in place of the synthetic file. The repository does not redistribute that file, because the OPSD time series package does not state its license in the package metadata, and its primary source is ENTSO-E.

Citation: Open Power System Data. 2020. Data Package Time series. Version 2020-10-06. https://doi.org/10.25832/time_series/2020-10-06. (Primary data from various sources, for a complete list see URL).
