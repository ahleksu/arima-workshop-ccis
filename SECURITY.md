# Security Policy

## Supported Versions

The project has no released version yet. After the first release, the latest tagged release on `main` receives security fixes. Older releases do not.

## Reporting a Vulnerability

Report suspected vulnerabilities by email to [help@ahleksu.dev](mailto:help@ahleksu.dev).

Do not open a public Issue containing exploit details, credentials, secrets, personal data, or other sensitive evidence.

Include:

- the affected component and version;
- impact and realistic attack conditions;
- reproducible steps or a minimal proof of concept;
- suggested remediation or workaround when known;
- a safe contact method for follow-up.

## Response and Coordinated Disclosure

The maintainer will acknowledge a report within 7 days. The maintainer will triage the report, share the assessment with the reporter, and prepare a fix. The maintainer will publish details only after the fix is available or after both parties agree on a date. A fixed vulnerability appears in `CHANGELOG.md` under `Security`.

## Ordinary Security Questions

Non-sensitive hardening requests or documentation corrections may use the normal Issue workflow. When uncertain, use the private reporting route.
